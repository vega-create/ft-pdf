Fillable PDF forms allow recipients to enter information directly into the document. They are widely used for applications, surveys, order forms, and any document that collects standardized information.

## Types of Form Fields

PDF forms support several field types. Text fields accept typed input. Check boxes allow yes/no selections. Radio buttons let users choose one option from a group. Dropdown menus present a list of choices. Buttons can submit form data or trigger actions.

## Creating Fillable Forms

### From Scratch

Adobe Acrobat Pro is the most common tool for creating PDF forms from scratch. You can add form fields to any PDF, set field properties, add validation rules, and create calculated fields.

### From Templates

Many organizations start with a designed document (often created in Word or InDesign) and then add form fields in a PDF editor. This approach separates design from functionality.

### Auto-Detection

Some PDF tools can automatically detect form fields in a document by recognizing blank lines, checkboxes, and other form-like elements. The results usually need manual adjustment but can save significant time.

## Form Design Tips

Label every field clearly. Group related fields together. Set tab order so users can move through the form logically using the Tab key. Provide clear instructions for complex fields. Use appropriate field sizes to guide expected input length.

## Distribution and Collection

Fillable PDFs can be distributed via email, web download, or document management systems. Recipients fill them out in any PDF reader. For data collection, consider using forms that submit data to a server rather than relying on recipients to email completed forms back.
